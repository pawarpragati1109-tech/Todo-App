# ✅ Todo App

A simple and responsive Todo Application built using **HTML, CSS, Bootstrap, and JavaScript**.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Store tasks using Local Storage
- Responsive UI using Bootstrap
- Custom styling with CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Local Storage

├── index.html
